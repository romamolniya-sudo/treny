# Тренировки Лёхи

Приложение по программе Лёхи на год: 73 упражнения с видео, дневник подходов,
учёт БЖУ, фото прогресса. Работает на телефоне, ничего не устанавливать.

## Что внутри

- **Сегодня** — какая тренировка следующая, БЖУ за день, счётчики.
- **Тренировка** — разминка + упражнения по порядку. У каждого: видео, мышцы, ключевые
  моменты техники, таблица подходов (вес × повторы), таймер отдыха, свой комментарий.
- **Еда** — БЖУ по дням, свой список продуктов, вес тела, графики за 14 дней.
- **Прогресс** — график рабочего веса по каждому упражнению, фото прогресса, журнал.
- **Программа** — все 3 цикла и 73 упражнения с видео.
- **Ещё** — правила Лёхи дословно, КБЖУ, голосовое, выжимка исследований, офлайн, настройки.

Приложение само считает: какой сейчас цикл и день, цель по углеводам на текущий месяц
(250 г + 12 г каждый месяц первые полгода) и когда пора **поднимать рабочий вес** —
по правилу Лёхи: зашло 10–12 повторов в первом подходе → со следующей тренировки больше вес.

## Состав

```
index.html      688 КБ   само приложение (иконки вшиты внутрь)
sw.js             3 КБ   офлайн-кэш
videos/          35 МБ   73 видео + голосовое, по ~500 КБ каждое
icon-*.png      190 КБ   запасные копии иконок
```

Каждый файл заведомо меньше 25 МБ — заливается через сайт GitHub, терминал не нужен.

## Как выложить на GitHub

1. Создай пустой репозиторий на <https://github.com/new>
   - Имя: например `trenirovki`
   - **Public**
   - НЕ ставь галочки «Add README», «.gitignore», «license» — репозиторий должен быть пустой.

2. На странице репозитория нажми ссылку **«uploading an existing file»**.

3. Открой папку `trenirovki-app` в Finder, выдели всё внутри (⌘A) и **перетащи мышкой**
   в окно браузера — вместе с папкой `videos`.

   Важно: именно перетащить. Кнопка «choose your files» не умеет выбирать папки,
   и `videos` через неё не загрузится.

   Если GitHub заругается на количество — залей в два захода: сначала файлы из корня,
   потом отдельно папку `videos`.

4. Внизу нажми **Commit changes**.

5. **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save**

6. Через 1–2 минуты сайт будет тут:
   `https://ТВОЙ_ЛОГИН.github.io/trenirovki/`

7. На айфоне: открой ссылку в Safari → **Поделиться → На экран «Домой»**.
   Появится иконка со штангистом, подпись — **«Тренировки»**.

## Сразу после установки — включи офлайн

Открой **Ещё → Офлайн-режим → «Скачать все видео в телефон»**. Это 35 МБ, делай по wi-fi.

После этого приложение работает **без интернета**: видео берутся из памяти телефона.
Без этого шага в зале с плохой связью видео будут подгружаться по одному.

## Про приватность

GitHub Pages **всегда публичный** — по ссылке сайт открыть может кто угодно.
Ссылку никто не найдёт без прямого адреса, но технически это открытый сайт.
Если видео Лёхи выкладывать в открытый доступ не хочется — скажи, сделаем на хостинге с паролем.

## Важно про данные

Все записи (веса, еда, фото, комментарии) хранятся **только в браузере телефона** —
никуда не отправляются. Из этого следует:

- Открывать нужно **по ссылке GitHub Pages**. Если открыть `index.html` напрямую из «Файлов»,
  браузер не даст ничего сохранить и офлайн не включится — приложение об этом предупредит.
- Раз в месяц жми **Ещё → Сохранить резервную копию**. Если очистить данные Safari,
  без копии история пропадёт.

В **Ещё → Настройки** поставь реальную **дату старта программы** — от неё считаются
месяц, цикл и цель по углеводам.
